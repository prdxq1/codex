# Лабораторная работа № 2. Цифровая обработка изображений

Первые два варианта задания (объём для оценки «удовлетворительно»):
1. Выделение контуров: Лаплас, Робертс, Собел.
2. Подавление гауссова шума: прямоугольное усреднение 3×3 и 5×5, гауссово усреднение 5×5 (σ=1,5).

Стили, поля, абзацные отступы, формулы и колонтитулы с PAGE взяты из предоставленного отчёта Кузьменко. Оглавление приведено к двум вариантам, номера согласованы с PDF. Для другой пагинации можно передать `--pages file.json` при сборке отчёта: JSON-массив из девяти номеров разделов в порядке оглавления.

## Сборка и запуск

Требуются C++17, GNU Make и компилятор g++ (или clang++). Внешние C++-зависимости включены в `include/`; интернет при сборке не нужен.

```sh
make -j2
make test
make run
```

На Windows удобно использовать MSYS2/MinGW с GNU Make; в Visual Studio создать два отдельных C++17 target: приложение (`Image.cpp`, `Filters.cpp`, `Source.cpp`) и тесты (`Image.cpp`, `Filters.cpp`, оба файла из `tests/`). Каталог заголовков — `include/`. Рабочий каталог запуска — корень проекта.

`make run` **заново генерирует** все входные изображения и результаты. Никакие фотографии из приложенных архивов не загружаются. Создаются квадрат и круг на однородном фоне, градиент и тонкие полосы. Одинаковый seed воспроизводит шум при одинаковой реализации стандартной библиотеки C++; `normal_distribution` может различаться между платформами.

`Image` поддерживает PNG, каналы 1–4, безопасный доступ вне границ и глубокое копирование. Его интерфейс не расширялся. Для 1–2 каналов `getColor` записывает яркость в `r`, оставляя `g` и `b` без изменения, как в предоставленных тестах. Для границ фильтров применяется репликация крайнего пикселя. Амплитуды контуров ограничиваются 255, без масштабирования по максимуму изображения.

## Проверка

В текущей среде: **16 тестов, 547 утверждений, все пройдены**. В исходных тестах неинициализированные переменные `g,b` заменены нулями, иначе сравнение с ними имело неопределённое поведение; проверяемые требования сохранены. Добавлены проверки импульсного отклика, постоянного изображения, симметрии Гаусса, границ и неверных параметров.

| Метод | MSE по всему изображению | PSNR, дБ | MSE на плоском фоне |
|---|---:|---:|---:|
| Зашумлённый вход | 602,198 | 20,3334 | 613,448 |
| Усреднение 3×3 | 232,661 | 24,4636 | 67,8715 |
| Усреднение 5×5 | 355,900 | 22,6175 | 23,5435 |
| Гаусс 5×5 | 252,240 | 24,1127 | 30,3212 |

Ошибки измеряются относительно чистого эталона. Область фона: 5 ≤ x < 45, 100 ≤ y < 200. Сильнейшее сглаживание не обязательно даёт лучшую общую ошибку: оно размывает границы и узкие полосы.
